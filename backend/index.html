Tips for a better PDF

01
Use the public landing page

Start at the section you want to preserve. The crawler follows links from that point.

02
Raise the page cap slowly

Try 10–25 pages first. Very large sites can take longer and produce very large PDFs.

03
Try screen styling

Choose Print styling only when a site's own print stylesheet produces a better result.

This tool captures browser-rendered pages, not server source code. Some videos, canvas apps, maps, protected pages, downloads and interactive states cannot be meaningfully represented in static PDF.
